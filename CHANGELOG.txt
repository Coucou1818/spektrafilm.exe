CHANGELOG for the film profiles and LUTs shipped with The Dyeworks
===================================================================

This file travels with SPEKTRAFILM_LICENSE.txt, which is shipped unchanged.
Andrea Volpato's licence asks that changes to the profiles and LUTs be
described here rather than in the licence.

The profiles are in src/spektrafilm/data/profiles/ (inside the application
folder: _internal/spektrafilm/data/profiles/). They are CC BY-SA 4.0, and so
are LUTs made from them. The original work is
https://github.com/andreavolpato/spektrafilm by Andrea Volpato.

Baseline: spektrafilm as of commit 28bf883 (2026-07-08), the point this fork
branched from. Everything below is measured against it.
